## Repeatable browser regression

`tests/refinement.browser.mjs` uses an existing Playwright tooling installation without adding a production or project development dependency. Set PLAYWRIGHT_MODULE to that installation's package directory if it is not resolvable normally, BASE_URL to the running build and EVIDENCE_PATH to a JSON output file. Example: `BASE_URL=http://127.0.0.1:3234 PLAYWRIGHT_MODULE=/path/to/tooling/node_modules/playwright node tests/refinement.browser.mjs`.
